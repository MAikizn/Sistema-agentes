# Entrega (niobe)

Aqui está um arquivo **SVG** pronto que gera uma cruz simples (estilo “+”).  
Basta copiar o código abaixo, colar em um editor de texto (por exemplo Notepad, VS Code, Sublime) e salvar com a extensão **`.svg`** (ex.: `cruz.svg`). Ao abrir o arquivo em qualquer navegador ou programa de edição vetorial (Inkscape, Illustrator, Figma, etc.) você terá a imagem da cruz.

```svg
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg
    xmlns="http://www.w3.org/2000/svg"
    width="512"
    height="512"
    viewBox="0 0 512 512"
    version="1.1">

  <!-- Fundo (opcional) -->
  <rect width="100%" height="100%" fill="transparent"/>

  <!-- Cruz central -->
  <g transform="translate(256,256)">
    <!-- Barra vertical -->
    <rect x="-32" y="-128" width="64" height="256" fill="#000000"/>
    <!-- Barra horizontal -->
    <rect x="-128" y="-32" width="256" height="64" fill="#000000"/>
  </g>
</svg>
```

### Como usar

| Etapa | O que fazer |
|-------|-------------|
| **1. Copiar** | Selecione todo o código acima (incluindo a linha `<?xml ...?>`). |
| **2. Colar** | Abra um editor de texto simples e cole o código. |
| **3. Salvar** | Salve o arquivo como `cruz.svg`. |
| **4. Visualizar / Exportar** | Abra o `.svg` no navegador ou em um programa de edição (Inkscape, Illustrator, Figma). Se precisar de PNG/JPG, use a opção *Exportar* do programa escolhido. |

#### Dicas de personalização
- **Cor**: troque `fill="#000000"` para a cor que desejar (ex.: `fill="#ff0000"` para vermelho).  
- **Espessura**: ajuste os valores `width="64"` e `height="256"` (vertical) / `width="256"` e `height="64"` (horizontal) para mudar a espessura e comprimento da cruz.  
- **Tamanho do canvas**: altere os atributos `width="512"` e `height="512"` no elemento `<svg>` para mudar a resolução final.  
- **Borda arredondada**: adicione `rx="8"` nos `<rect>` se quiser cantos suavizados.
