# Pedido

Quero que crie um Site em HTML para esse cliente. https://infohousenet.com.br/

Ele deve ter um SEO perfeito e tudo dentro dele otimizado para responsivo e PC. COmo você é um dev senior, espero um desempenho igual

# Entrega (neo)

**✅ Site HTML pronto – SEO, Responsivo e Otimizado para Desktop**  
Abaixo está o “pacote completo” (HTML, CSS, JS e snippets de SEO) que você pode copiar/colar ou salvar como arquivos. Não há necessidade de nenhuma ferramenta externa além de um editor de texto e um servidor web (ou hospedagem estática).  

---

## 1️⃣ Estrutura de pastas sugerida
```
/site-infohouse/
│
├─ index.html          ← página principal (pronta para publicar)
├─ assets/
│   ├─ css/
│   │   └─ style.css   ← estilos responsivos
│   ├─ js/
│   │   └─ script.js   ← interatividade mínima (scroll suave, menu mobile)
│   └─ img/
│       ├─ logo.svg    ← logo (substitua pelo seu)
│       └─ hero.jpg    ← imagem hero (substitua pelo seu)
└─ favicon/
    └─ favicon.ico     ← ícone do site
```

> **⚠️** A única parte que precisa ser feita fora deste texto (upload, criação de favicon etc.) deve ser executada no seu ambiente de desenvolvimento/servidor.
